# 📌 Proyecto Empresa – Aplicación de Gestión

Aplicación web desarrollada como proyecto formativo en el ciclo **DAW/DAM**, orientada a la gestión de incidencias, usuarios y tareas en un entorno empresarial simulado.  
El objetivo es aplicar buenas prácticas de desarrollo backend con **Laravel** y documentar la API con **Swagger**.

---

## 🚀 Tecnologías utilizadas
- **Backend:** Laravel (PHP)
- **Base de datos:** MySQL
- **Documentación API:** Swagger
- **Control de versiones:** Git y GitHub

---

## ℹ️ Sobre esta rama (`feature/remove-vite`)
Esta rama está optimizada para actuar como una **API Pura**. Se ha eliminado el empaquetador Vite y todas las dependencias de Node.js/NPM. Esto facilita el despliegue en entornos de producción y evita bloqueos de host (Allowed Hosts) al servir la API para el frontend de Angular.
